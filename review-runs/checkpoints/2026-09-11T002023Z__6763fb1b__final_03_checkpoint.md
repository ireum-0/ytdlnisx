## New confirmed subfinding

`BUG-LOCALADD-01 / serialized-downloadPath substring collision` — NEW / P2 subfinding / OPEN.

Current production path:

`LocalAdd entry -> tree exact lookup -> HistoryDao.getItemByDownloadPath(escapeLikeQuery(uriString)) -> non-null suppresses entry`.

The DAO query is:

`SELECT * FROM history WHERE downloadPath LIKE '%' || :path || '%' ESCAPE '\\' LIMIT 1`

while `HistoryItem.downloadPath` is a `List<String>` persisted by Room's converter as `Gson.toJson(list)`.

Therefore exact collection membership is approximated by substring containment in the serialized JSON. A distinct new URI/path that is a proper substring of an existing stored download path can be rejected before metadata, matching, History insertion, or pending publication.

Concrete reproduction:

- existing History row: `downloadPath = ["content://provider/document/abcde"]`
- new LocalAdd entry: `content://provider/document/abc`
- serialized existing value contains the shorter URI as a substring;
- SQL `LIKE '%content://provider/document/abc%'` matches;
- `LocalAddWorker` sees non-null and executes `return@forEach`;
- valid sibling is silently suppressed.

`escapeLikeQuery()` protects wildcard characters but cannot change the deliberate leading/trailing `%` substring semantics.

Disposition: same coarse LocalAdd identity/suppression authority root as prior basename/provider-documentId subcases; do not increment canonical P2 root count.

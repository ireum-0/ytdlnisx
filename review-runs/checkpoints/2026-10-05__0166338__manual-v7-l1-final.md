BUG-UPDATER-02 remains OPEN P2. L1 deep review confirms the legacy desired-generation residual and refines its correction contract.

e3ded5a introduced destination-local ytdlp_source_generation without an independent generation-domain discriminator. c38a753 later introduced the private provenance epoch but deliberately preserved ytdlp_source_generation. Therefore after c38 migration, a destination-generated Long and a supported pre-e3 restore-imported Long can have the same durable representation: private provenance epoch=1, same source/label, same generation, and after re-proof matching committed proof.

The existing private epoch proves provenance-proof migration generation, not desired-generation origin.

The current correction prompt is therefore internally overconstrained: it requires every positive foreign Long to be rejected as destination identity while also requiring every valid current-epoch generation to be preserved. Those classes are indistinguishable in current durable state.

The narrow implementable correction is a separate desired-generation-domain discriminator unavailable to pre-correction producers. Until that new discriminator is current, all existing generation representations are origin-ambiguous even when private provenance epoch=1. A one-time generation-domain rebase is allowed if valid source intent is preserved, committed/pending proof is retired, the new generation write is durable before discriminator publication, replay is crash-safe, and typed/cast legacy generation reads cannot occur before repair.

Once the new generation-domain discriminator is current, valid destination generations and genuine current-domain exhaustion semantics must be preserved exactly.

Reviewed production call sites show no separate durable expected-generation carrier: UpdateYTDLWorker does not persist one; UpdateSettingsFragment and StartupYtdlpUpdateOwner carry generation only in-process. Thus one-time upgrade rebase is feasible if proof/pending authority is invalidated and migration is serialized correctly.

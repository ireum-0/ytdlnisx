### P2-1 EXISTING — ordinary History post-commit replay
Ordinary History insertion can durably commit before Download-row semantic terminalization. Only History replacement receives the dedicated `HISTORY_FINALIZATION` recovery carrier. Process death in the ordinary insert -> Download complete/delete window can leave the row runnable/recoverable and permit producer replay.

### P2-2 EXISTING — provider post-commit same-source recreation
A finalized provider destination may be durably recorded before local source retirement. If source deletion fails, the same attempt retries that source. `PublicationRecoveryJournal.reserveIntent()` returns success for a source that already has `destinationPath`, so provider creation is not stopped at the pre-create gate. A collision-suffixed second provider object may be created; rollback failure can leave both objects.

### P2-3 EXISTING — opaque provider UNKNOWN lacks convergence owner
UNKNOWN is now correctly fail-closed and durable, but production still has no exact external-object discovery, deterministic rollback, provider-idempotent reconciliation, or explicit authority transfer/revocation owner. Safety fencing is not recovery convergence.

### P2-4 NEW — Terminal pre-generation `NATIVE_STARTED` can become permanent recovery debt
`TerminalDownloadWorker` durably writes `NATIVE_STARTED` before entering `YoutubeDLCompat.execute()`. `executeWithQuiescence()` then performs runtime initialization, binary checks, argument preparation, `YtdlpNativeProcessBarrier.prepare()`, ProcessBuilder construction/start, in-memory registration, and only afterwards invokes `onProcessRegistered`, where the Terminal execution journal finally binds the immutable generation token. An exception or process death anywhere after `NATIVE_STARTED` but before token binding leaves a native-started witness with no exact generation token. `TerminalExecutionRecovery.proveNativeQuiescent()` explicitly refuses to prove/recover such a witness. Startup reconciliation therefore retains it as deferred/nonterminal debt and later admission returns BLOCKED. Before barrier prepare, this can be a permanent false-positive debt even though no native generation existed; after barrier prepare/start but before callback persistence, an exact generation can exist but the Terminal witness does not carry the token needed to address it.

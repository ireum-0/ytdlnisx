## Revalidated findings

### `BUG-LOCALADD-01` — EXISTING / P2 / OPEN

Violated invariant: exact local storage identity must preserve semantic granularity; filename/coarse or unproved tree identity must not silently discard a distinct file.

Production path/evidence: `LocalAddStorageIdentityPolicy.relativePath()` still proves only provider-authority equality, then interprets provider document IDs by textual prefix removal to derive a tree-relative path. Android's authoritative DocumentsContract contract treats document IDs as opaque provider-interpreted values; same provider is not descendant authority. A wrongly associated same-provider tree can therefore collapse two distinct files to the same `tree:<tree>|<relative>` identity before final admission. Final transactional admission cannot repair an already-collapsed identity.

Affected production files include `LocalAddStorageIdentityPolicy.kt`, LocalAdd UI/worker metadata producers, and `HistoryKeywordAssignmentRepository.kt` final admission consumer.

Disposition: existing P2 OPEN; runtime manifestation `NOT_VERIFIED` in this run.

### `BUG-CLEANUP-01` — EXISTING / P2 / OPEN

Production path/evidence: `CleanUpLeftoverDownloads.doWork()` calls `CleanupScheduleCoordinator.isCurrentOccurrence()` before destructive cleanup, but that point check releases the coordinator lock before `deleteCancelled()`, `deleteErrored()`, and cache deletion. WorkManager cancellation is best-effort for already executing work and is not an application-level mutation lease.

Affected production files include `CleanupScheduleCoordinator.kt`, `CleanUpLeftoverDownloads.kt`, and settings reconfiguration consumer path.

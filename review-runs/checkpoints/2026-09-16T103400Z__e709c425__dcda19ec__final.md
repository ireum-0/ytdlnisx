## Findings / dispositions
### BUG-CLEANUP-01 / F10 — P2 OPEN, confirmed residual
Violated invariant: a failed required authority write must not later become durable/authoritative through an unrelated subsequent write; recovery must preserve the last confirmed durable generation/cadence/effect tuple.

Production path: `CleanupScheduleCoordinator.commitCritical` snapshots the pre-attempt critical state and installs `criticalDurabilityFence` when `SharedPreferences.Editor.commit()` returns false. Reads through `criticalString/int/long` then correctly consult the fence. However, the underlying Android SharedPreferences in-process map has already been mutated by `commitToMemory()`. A later critical editor is created against that contaminated SharedPreferences instance. If that later commit succeeds, Android writes the current map snapshot to disk, which includes memory-only keys from the earlier failed commit; `commitCritical` then unconditionally clears `criticalDurabilityFence` on success.

Concrete reproduction/evidence:
1. Durable authority is DAILY/generation A.
2. `configure(WEEKLY)` constructs a full authority editor for generation B; its `commit()` returns false after Android `commitToMemory()` has exposed WEEKLY/B in the same-process map. The fence preserves DAILY/A for coordinator reads.
3. Old DAILY/A work is still allowed by fenced reads to perform a later critical effect-phase/journal transition.
4. That editor changes only its intended effect fields, but Android's disk write uses the current SharedPreferences map snapshot. The map still contains WEEKLY/B from step 2.
5. If this later commit succeeds, WEEKLY/B can be persisted as collateral even though its required authority commit failed and no matching configure scheduling handoff was accepted. `commitCritical` then clears the fence and subsequent reads accept the contaminated durable state.

Affected files: `app/src/main/java/com/ireum/ytdl/work/CleanupScheduleCoordinator.kt`; downstream cleanup worker/journal authority consumers.
Disposition: existing root, distinct L1 residual; not a new root. F10 remains OPEN.

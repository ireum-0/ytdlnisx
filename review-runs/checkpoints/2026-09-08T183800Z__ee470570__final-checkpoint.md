Concrete production path:
1. Provider completion becomes UNKNOWN.
2. Download persists Error + `PUBLICATION_OUTCOME_UNKNOWN`.
3. `DownloadIssueClassifier` adds `RECONFIGURE` for this code.
4. Error UI exposes Configure and opens the same Download item.
5. `queueDownloads()` accepts a RECONFIGURED retry, increments retry metadata, and retains the existing nonblank operationId.
6. A new execution is queued.
7. Before normal continuation, `recoverPriorPublication()` searches same downloadId + same operationId, finds the prior UNKNOWN journal, terminalizes it, and throws `UnknownProviderPublicationException`.
8. The item returns to the same terminal Error without any resolution of the UNKNOWN external object/fence.
